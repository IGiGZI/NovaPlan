Career Path - Flutter (Dark mode) - Android focused
---------------------------------------------------

This package contains a minimal Flutter UI converted from a Figma Career Path design.
It includes:
- A dark-themed Home screen with search and chips.
- Career cards list.
- Detail screen per career.
- Placeholder assets inside assets/images/.

Flutter version compatibility: tested conceptually with Flutter 3.24.0 / Dart 3.5.0.

How to run:
1. Unzip the project into a folder.
2. From the project root run:
   flutter pub get
   flutter run

Notes:
- Replace placeholder images in assets/images/ with your exported Figma assets for a closer visual match.
- No Firebase configuration is included.
